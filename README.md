# チケット予約フォーム (ticket_form)

ジェットラグプロデュース **一身上の都合により**（作・演出：山崎洋平）における、**安藤理樹扱い専用** チケットWeb予約フォームシステムです。

フロントエンドを **GitHub Pages** で静的ホスト（完全無料）し、バックエンドに **Google フォーム（＋Google スプレッドシート）** のデータ連携基盤を利用することで、**初期費用・ランニングコスト0円** で高機能かつ自由なUI/UXを実現しています。

---

## 🌟 特徴・機能

1. **洗練された Apple-like Clean White UI**:
   - オフホワイト基調（`#fbfbfd`）と純白カード、微細な多層シャドウ、Apple Blue（`#0071e3`）のアクセント。
   - ピルボタン（角丸カプセル型バッジ）による専用予約フォーム表記。
2. **最新のモダンフロントエンド構成**:
   - CSSフレームワーク: [**Lism CSS**](https://lism-css.com/)（レイアウトプリミティブ指向）
   - フォント: [**Gen Interface JP**](https://gen.typesetting.jp/)（UI/UXに特化したオープンソース和欧混植フォント）
   - 外部ランタイム非依存（Vanilla HTML5 / CSS3 / JavaScript）で超軽量・高速表示。
3. **チラシ画像の大型化 ＆ Lightbox 拡大表示**:
   - ヘッダー横幅の約半分を使って迫力ある公式フライヤー（WebP高解像度最適化）を表示。
   - クリック・タップですりガラス背景の **Lightboxモーダル** が起動し、細部まで高精細に閲覧可能（キーボード `ESC` や背景タップで即座に閉じる快適設計）。
4. **精密な料金グリッド表示 ＆ プレミアム特典ポップアップ**:
   - 券種（一般 7,500円 ／ プレミアム 9,500円）が固定グリッドで縦一列に精密整列。
   - 「プレミアム」の文字にホバー（またはタップ）すると、ふわりと特典内容（最前2列確約＋サイン入りポートレート付）が吹き出しポップアップ。
   - 「※全席指定・税込」を料金ラベル直下に集約。
   - 主催公式サイト（ジェットラグ）への直通リンクを配置。
5. **公演タイムテーブル（星取表）の内蔵**:
   - 2026年11月25日(水)〜11月29日(日) 全9ステージの開演時間（13:00 / 14:00 / 17:00 / 19:00）をひと目で確認可能。
   - 見出しの右横に開場・受付案内（開演40分前受付／30分前客席開場）をインライン配置。
6. **公式プレイガイド（カンフェティ ＆ チケットぴあ）直通リンク**:
   - 出演者個人窓口での受付が気になる方向けに、公式プレイガイドの販売ページへのリンクをご案内文に設置。
7. **CORS制約の確実な回避 & 二重送信防止**:
   - 非表示iframe（`target="hidden_iframe"`）を用いた安全・確実なGoogleフォーム直接POST連携。
   - リアルタイム入力検証、送信前「確認モーダル」、送信中スピナーアニメーション＆ボタン非活性化を標準装備。
8. **モック（テスト）モード標準搭載**:
   - `js/config.js` の `isMockMode: true` 時は、Googleフォームへの実送信を行わずにローカル環境やブラウザ単体で完了フローやバリデーションの動作確認が可能。
9. **扱い窓口の自動集約（安藤理樹専用）**:
   - 本フォームおよび受信用Googleフォーム／スプレッドシートは安藤理樹様専用の窓口として運用されるため、Googleフォーム側に「扱い窓口」の設問を作成する必要はありません（収集された回答はすべて自動的に安藤扱いとして集約されます）。
10. **堅牢なセキュリティ・スパム対策**:
   - ハニーポット（不可視フィールド）による自動巡回スパムボットの検知・遮断。
   - 扱い窓口の固定化（URLパラメータ改ざん防止）。
   - `.gitignore` によるGoogleドライブ同期ファイル（`.gform`等）の公開防止。
11. **前日23:59締切制御 & モバイル最適化**:
   - 各ステージの前日23:59:59を過ぎた公演はプルダウンから自動非表示化。万一ページを開いたまま日付を越えて送信しようとした場合も二重に検知してエラー警告・送信遮断。全公演終了時は予約終了メッセージを表示。
   - スマートフォン表示（幅768px以下）では「タイトル・出演者 → チラシ画像 → 公演概要（日程・会場・料金） → タイムテーブル」の最適化された縦配置フローに自動切り替え。
   - メールアドレス欄の必須バッジと注釈テキストを分離し、モバイルでもすっきり1行表示。

## 💻 ローカル環境での動作確認

本プロジェクトは静的ファイルのみで構成されているため、ローカルで手軽にプレビュー可能です。

```bash
# ticket_form ディレクトリに移動
cd ticket_form

# Python 3 の簡易HTTPサーバーを起動
python3 -m http.server 8000
```
ブラウザで `http://localhost:8000` を開きます。
`js/config.js` 内の `isMockMode: true` の状態であれば、GoogleフォームのURLやIDを設定する前でも、入力〜確認モーダル〜完了画面までの全フローを安全にテストできます。

## 🚀 導入・セットアップ手順

### ステップ1: Google フォームの作成

[Google フォーム](https://forms.google.com/) にアクセスし、新しいフォームを「空白」から作成します。
以下の内容をそのままコピー＆ペーストして各項目を設定してください。

#### 1. フォームの基本情報
- **フォームのタイトル**:
  ```
  『一身上の都合により』安藤理樹扱い チケット予約受付
  ```
- **フォームの説明**:
  ```
  ジェットラグプロデュース『一身上の都合により』安藤理樹扱い専用チケット予約フォームの受信用バックエンドです。
  ```

#### 2. 設問の設定（全7問）
※本フォームは安藤理樹様専用の窓口として独立運用するため、「扱い窓口」の設問は作成不要です。

| # | 設問のタイトル | 質問形式 | 必須 | 選択肢・設定内容 |
| :- | :--- | :--- | :-: | :--- |
| **1** | **お名前** | 記述式 | **必須** | - |
| **2** | **フリガナ** | 記述式 | **必須** | - |
| **3** | **メールアドレス** | 記述式 | **必須** | - |
| **4** | **ご観劇日時** | プルダウン | **必須** | 以下の9行をそのまま追加：<br>・`2026年11月25日(水) 19:00開演`<br>・`2026年11月26日(木) 14:00開演`<br>・`2026年11月26日(木) 19:00開演`<br>・`2026年11月27日(金) 14:00開演`<br>・`2026年11月27日(金) 19:00開演`<br>・`2026年11月28日(土) 13:00開演`<br>・`2026年11月28日(土) 17:00開演`<br>・`2026年11月29日(日) 13:00開演`<br>・`2026年11月29日(日) 17:00開演` |
| **5** | **券種** | プルダウン | **必須** | 以下の2行を追加：<br>・`一般指定席`<br>・`プレミアム席（最前2列確約・サイン入りポートレート付）` |
| **6** | **チケット枚数** | プルダウン | **必須** | 以下の4行を追加：<br>・`1枚`<br>・`2枚`<br>・`3枚`<br>・`4枚` |
| **7** | **備考** | 段落 | 任意 | 説明（任意）: `領収書のご希望宛名、車椅子でのご来場、応援メッセージ等` |

#### 3. 重要な初期設定（メールアドレス収集のOFF）
1. フォーム上部の **「設定」** タブをクリックします。
2. **「回答」** の項目を展開します。
3. **「メールアドレスを収集する」** を **「収集しない」** に設定します（設問 #3 で直接確実に取得するため）。

### ステップ2: Google フォームのエンドポイントと entry ID を抽出

1. 作成したGoogleフォームの右上にある **「目のアイコン（プレビュー）」** をクリックしてプレビュー画面を開きます。
2. プレビュー画面のURLは以下のようになっています：
   ```
   https://docs.google.com/forms/d/e/{FORM_ID}/viewform
   ```
   送信先URLは末尾を `formResponse` に変更した以下となります：
   ```
   https://docs.google.com/forms/d/e/{FORM_ID}/formResponse
   ```
3. プレビュー画面でブラウザの開発者ツール（F12 または 右クリック ➔「検証」）を開きます。
4. 各入力欄（input / select / textarea要素）を検証ツールで確認し、`name="entry.XXXXXXXXX"` となっている属性値をメモします。
   - お名前 ➔ `entry.2100160247`
   - フリガナ ➔ `entry.1689145255`
   - メールアドレス ➔ `entry.1389300706`
   - ご観劇日時 ➔ `entry.727708549`
   - 券種 ➔ `entry.1948786286`
   - チケット枚数 ➔ `entry.1258909965`
   - 備考 ➔ `entry.438285804`

### ステップ4: スプレッドシート（予約台帳）と稽古場運用の連携

1. Googleフォームの「回答」タブから **「スプレッドシートにリンク」** を選択し、回答受信用スプレッドシートを作成します。
2. 作成されたスプレッドシートを開き、Googleフォーム自動入力列（A〜H列）の右側に、以下の運用管理カラムを追加します：

| A〜H列（自動入力） | I列（手動追加） | J列（手動追加） | K列（手動追加） |
| :--- | :--- | :--- | :--- |
| タイムスタンプ / お名前 / フリガナ / メール / 日時 / 券種 / 枚数 / 備考 | **ノート転記ステータス** | **確定メール送信日** | **座席・配席メモ** |
| 自動入力 | `未転記` / `転記済` | `2026/11/10` | 領収書宛名、通路側希望 など |

3. **日々の運用フロー**:
   1. 予約が入るとスプレッドシートにリアルタイムで1行追加されます。
   2. 稽古場にてスプレッドシートの「未転記」行を確認し、現地の紙ノート（座席配席表）へ記入。
   3. ノート記入後、スプレッドシートのステータスを `転記済` に更新。
   4. 残席確保の確認後、予約者宛てに確定メールを送信し、確定送信日を記録。

### ステップ5: GitHub Pages へのデプロイ

1. 本 `ticket_form` ディレクトリの内容を、GitHubリポジトリ（例: `ticket-reservation`）の `main` ブランチにプッシュします。
2. GitHubのリポジトリページから **Settings > Pages** を開きます。
3. **Build and deployment** の Source で **Deploy from a branch** を選択し、Branch を `main` / `/(root)` に設定して「Save」をクリックします。
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` に公開URLが生成されます。
